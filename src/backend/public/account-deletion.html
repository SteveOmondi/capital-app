The 8-Step Profile Deletion Journey

Our secure account deletion process protects users against accidental or unauthorized account deletion through 2-factor email confirmation and mobile deep linking:

1

User Requests Account Deletion

The customer initiates profile deletion from within the Capital FM mobile app settings menu or via our web portal.

2

App Sends Request to Backend

The app transmits the account deletion request to our secure backend API (POST /api/v1/user/delete-request).

3

Server Returns Cryptographic Deletion Token

The server generates a unique, 24-hour expiration token (del_...) and returns it securely to the mobile app.

4

App Generates Deep Link & Sends to Server

The app formats a custom mobile deep link (capitalfm://delete-account?token=...) and posts it back to the backend gateway.

5

Server Emails Link to Customer Inbox

Our server dispatches an automated, formatted confirmation email containing the verification link directly to the customer's inbox.

6

Customer Taps Email Link & Launches Confirmation Screen

The customer clicks the link in their email client, automatically launching the Capital FM mobile app to the Confirm Account Deletion screen.

7

Final Confirmation Sent to Backend

Upon final confirmation tap in the app, the token is sent to the backend server (POST /api/v1/user/confirm-deletion).

8

Backend Purges Profile & Returns Success

The backend permanently deletes the user profile, server-synced audio favorites, push notification tokens, and all personal record associations.
