# 📻 Capital FM Backend Gateway (Node.js + TypeScript)

Production-ready Backend-for-Frontend (BFF) API Gateway service for Capital FM Kenya.

## Quick Commands

- **Install Dependencies**: `npm install`
- **Database Push**: `npx prisma db push`
- **Start Dev Server**: `npm run dev`
- **Run Tests**: `npm test`
- **Swagger Docs**: `http://localhost:3000/docs`
